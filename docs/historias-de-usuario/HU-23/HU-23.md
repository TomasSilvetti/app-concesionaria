# HU-23: Dashboard de Métricas

**Como** usuario de la concesionaria,
**quiero** acceder a un módulo de métricas con KPIs ejecutivos, rotación de stock, cobros y rentabilidad de inversiones,
**para** tomar decisiones informadas sobre el negocio a partir de datos consolidados en un solo lugar.

## Descripción

El módulo "Métricas" es una nueva sección accesible desde el sidebar que presenta un dashboard unificado con los indicadores más relevantes del negocio. Cuenta con un selector de período global en la parte superior que afecta a todas las visualizaciones simultáneamente. El módulo incluye tarjetas KPI, gráficos de rotación, cobros y una tabla de ROI por inversor.

## Criterios de aceptación

- [ ] Existe un nuevo ítem "Métricas" en el sidebar que navega a una nueva ruta del módulo
- [ ] El selector de período global (semana, mes actual, mes anterior, año, rango personalizado) aparece en la parte superior y afecta todas las métricas al cambiar
- [ ] Se muestran 5 tarjetas KPI: Ganancia neta del mes (con delta vs período anterior), Ticket promedio de venta, Tasa de conversión (ops cerradas / total), Capital inmovilizado en stock, Deuda total pendiente
- [ ] Se muestra una barra apilada de aging de deuda con rangos 0-30 días, 31-60 días y +60 días
- [ ] Se muestra un line chart de rotación mensual (operaciones cerradas / stock disponible por mes)
- [ ] Se muestra un pie chart de cobros por método de pago (suma de montos por método en el período)
- [ ] Se muestra una tabla de ROI por inversor con columnas: Inversor, Monto Aportado, Retorno, ROI%
- [ ] Cuando no hay datos en el período, las tarjetas muestran "—" o 0 y los gráficos muestran un estado vacío con mensaje descriptivo
- [ ] Cuando no hay inversiones en el período, la tabla muestra el mensaje "No hay inversiones registradas en este período"
- [ ] Todos los usuarios autenticados tienen acceso al módulo

## Flujos

### Flujo principal (escenario de éxito)

1. El usuario hace clic en "Métricas" en el sidebar
2. El sistema navega a la ruta del módulo y muestra el dashboard
3. El período por defecto es el mes actual
4. El sistema carga y renderiza todas las secciones con los datos del período:
   - Fila de 5 tarjetas KPI
   - Barra apilada de aging de deuda
   - Line chart de rotación mensual
   - Pie chart de cobros por método de pago
   - Tabla de ROI por inversor
5. El usuario selecciona un período diferente desde el selector global
6. Todas las métricas y gráficos se actualizan simultáneamente con los datos del nuevo período

### Flujo alternativo 1 — Sin datos en el período seleccionado

1. El usuario selecciona un período sin operaciones, pagos ni gastos registrados
2. Las tarjetas KPI muestran "—" o 0 según corresponda
3. Los gráficos muestran un estado vacío con un mensaje descriptivo (ej: "Sin datos para el período seleccionado")
4. La tabla de ROI muestra el mensaje "No hay inversiones registradas en este período"

### Flujo alternativo 2 — Sin inversores registrados en el período

1. El sistema no encuentra inversiones vinculadas a operaciones dentro del período seleccionado
2. La sección de tabla de ROI por inversor muestra el mensaje "No hay inversiones registradas en este período"
3. El resto del dashboard se muestra con normalidad

## Notas técnicas

⚠️ **Base de datos:** Esta historia requiere consultas sobre las entidades `Operation`, `Pago`, `Expense`, `VehicleStock`, `Inversion` e `InversionParticipante`. Todas las consultas deben filtrarse por `clienteId` y por el rango de fechas del período seleccionado. El delta de ganancia neta requiere calcular el mismo indicador para el período inmediatamente anterior al seleccionado. El ROI por inversor se calcula como `(retorno / montoAporte) * 100` usando los campos `porcentajeUtilidad` y `montoAporte` de `InversionParticipante`.
