# HU-21-5: Tutorial guiado — Módulo Pendientes

**Como** usuario demo,
**quiero** que el tutorial me guíe por el módulo de Pendientes,
**para** entender cómo visualizar y gestionar las tareas pendientes en la aplicación.

## Descripción

Esta subhistoria define los pasos del tutorial Driver.js correspondientes al módulo de Pendientes. Es el último módulo del tour. Al completarlo, se dispara el proceso de cleanup que restaura los datos base del usuario demo.

## Criterios de aceptación

- [ ] El tutorial navega automáticamente al módulo Pendientes al completar el módulo Stock.
- [ ] Cada paso resalta el elemento correspondiente y muestra un tooltip con título y descripción.
- [ ] El usuario puede avanzar al siguiente paso con el botón "Siguiente" del tooltip.
- [ ] No existe botón para cerrar o saltear el tour.
- [ ] Al completar el último paso, se muestra un mensaje de cierre del tutorial (ej: "¡Eso es todo! Ya conocés la aplicación.").
- [ ] Tras cerrar el mensaje final, se ejecuta el proceso de cleanup: se compara el estado actual del `clientID` demo con el snapshot tomado al inicio y se eliminan los registros nuevos.
- [ ] El usuario queda en el módulo Pendientes con los datos base restaurados.

## Notas técnicas

⚠️ Los selectores de elementos deben coincidir con los `id` o `data-tour` attributes definidos en los componentes del módulo Pendientes.

⚠️ **Cleanup:** Al dispararse el evento `onDestroyStarted` o equivalente de Driver.js en el último paso, se debe llamar al endpoint `/api/demo/cleanup` que recibe el snapshot inicial y el estado actual del `clientID` demo, y elimina los registros nuevos.
