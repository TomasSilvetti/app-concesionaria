# HU-21-2: Tutorial guiado — Módulo Finanzas

**Como** usuario demo,
**quiero** que el tutorial me guíe por el módulo de Finanzas,
**para** entender cómo visualizar y gestionar la información financiera en la aplicación.

## Descripción

Esta subhistoria define los pasos del tutorial Driver.js correspondientes al módulo de Finanzas. Es el segundo módulo del tour, al que se accede automáticamente al finalizar HU-21-1.

## Criterios de aceptación

- [ ] El tutorial navega automáticamente al módulo Finanzas al completar el módulo Operaciones.
- [ ] Cada paso resalta el elemento correspondiente y muestra un tooltip con título y descripción.
- [ ] El usuario puede avanzar al siguiente paso con el botón "Siguiente" del tooltip.
- [ ] No existe botón para cerrar o saltear el tour.
- [ ] Al completar el último paso de este módulo, el tour avanza automáticamente al módulo Cobranzas (HU-21-3).
