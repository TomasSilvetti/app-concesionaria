# HU-21-1: Tutorial guiado — Módulo Operaciones

**Como** usuario demo,
**quiero** que el tutorial me guíe por el módulo de Operaciones,
**para** entender cómo visualizar, filtrar y editar operaciones en la aplicación.

## Descripción

Esta subhistoria define los pasos del tutorial Driver.js correspondientes al módulo de Operaciones. Es el primer módulo del tour. Cada paso resalta un elemento de la pantalla con el efecto spotlight y muestra un tooltip explicativo.

## Criterios de aceptación

- [ ] El tutorial navega automáticamente al módulo Operaciones al iniciar.
- [ ] Cada paso resalta el elemento correspondiente y muestra un tooltip con título y descripción.
- [ ] El usuario puede avanzar al siguiente paso con el botón "Siguiente" del tooltip.
- [ ] No existe botón para cerrar o saltear el tour.
- [ ] Al completar el último paso de este módulo, el tour avanza automáticamente al módulo Finanzas (HU-21-2).

## Pasos del tutorial

> ✏️ **Completar por el desarrollador.**
> Definir aquí cada paso con el selector del elemento a resaltar, el título y la descripción del tooltip.

```
Paso 1:
  Elemento: resalta la tabla de operaciones
  Título: Tabla de Operaciones
  Descripción: Esta tabla muestra todas las operaciones registradas en el sistema. Puedes ver el número de operación, el vehículo involucrado, el estado actual y la fecha de creación. Utiliza esta tabla para tener una visión general de todas las operaciones en curso y pasadas.

Paso 2:
  Elemento: seccion filtros (resalta el contenedor de filtros)
  Título: Filtros de Búsqueda
  Descripción: Utiliza estos filtros para buscar operaciones específicas según criterios como la marca del vehículo, el estado, etc.

Paso 3:
  Elemento: boton nueva operacion +
  Título: vamos a crear una nueva operación
  Descripción: haz click en el botón "+ Nueva Operación" para abrir el formulario de creación de operaciones. En el próximo módulo del tour, te guiaremos por el proceso de creación paso a paso.

paso 4:
  Elemento: seccion datos de la operacion
  Título: Datos de la operacion
  Descripción: completa los tres datos principales, empecemos una venta de tipo 0km, que sera cuando el cliente compra un auto nuevo y tu haces de intermediario entre el cliente y la concesionaria.
  Luego selecciona la fecha de inicio y el nombre del comprador del vehiculo

  paso 5:
  Elemento: Seccion informacion del vehiculo
  Título: Guardar operación 
  Descripción: Completa los datos del vehículo como marca, modelo, año, etc. 
  

...
```

## Notas técnicas

⚠️ Los selectores de elementos deben coincidir con los `id` o `data-tour` attributes definidos en los componentes del módulo Operaciones.
