# HU-21-3: Tutorial guiado — Módulo Cobranzas

**Como** usuario demo,
**quiero** que el tutorial me guíe por el módulo de Cobranzas,
**para** entender cómo visualizar y gestionar las cobranzas en la aplicación.

## Descripción

Esta subhistoria define los pasos del tutorial Driver.js correspondientes al módulo de Cobranzas. Es el tercer módulo del tour, al que se accede automáticamente al finalizar HU-21-2.

## Criterios de aceptación

- [ ] El tutorial navega automáticamente al módulo Cobranzas al completar el módulo Finanzas.
- [ ] Cada paso resalta el elemento correspondiente y muestra un tooltip con título y descripción.
- [ ] El usuario puede avanzar al siguiente paso con el botón "Siguiente" del tooltip.
- [ ] No existe botón para cerrar o saltear el tour.
- [ ] Al completar el último paso de este módulo, el tour avanza automáticamente al módulo Stock (HU-21-4).
